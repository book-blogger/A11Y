# A11Y
Theme and Font Size Switcher for web accessibility.

Live preview on my [website](https://horse.jp.net/)

credit to [crotovane](https://crotovane.neocities.org/) for the inspiration and [WebAIM](https://webaim.org/) for helping me learn about web accessibility 
## Features
* Designed to work around html's native select dropdowns
* Automatically works with yours device's Light or Dark theme
* New themes can easily added base on the template
## How To Use
* make sure to store files locally to your website or where ever is easiest to link
* you can use the script file in the head attribute if you use defer in the tag, otherwise place it before the ending body tag
* place the html anywhere you want as it does not require a parent container
* select menu can be styled (with limits), but the css it mainly for setting up your site's themes
* adding new themes requires adding colors under a new name (ex: data-theme=example) in the css and inserting the corresponding button to the html (ex: value="example") 
* have fun!
